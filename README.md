# ناشر منشورات قناتي Telegram إلى قناة منصة الناصر القانونية

ينشئ هذا المشروع نسخة من المنشورات الجديدة الظاهرة في صفحات المعاينة العامة للقناتين `@AbdmomenShjaaAldeen` و`@qada_a`، ثم ينشر النص والصور أو الفيديوهات المتاحة عبر Telegram Bot API في قناتك. لا يستخدم Userbot أو بيانات دخول حساب شخصي.

يُنشر الخبر بهذا القالب:

```text
نص الخبر
ــــــــــــــــــــــــــــ
للاشتراك بالقناة عبر تيليجرام:
https://t.me/muen2025
```

يحافظ السكربت على الرموز التعبيرية والرموز الموجودة في بداية الخبر العربي، وينظف النص العربي من النسخة الإنجليزية وروابط المصدر، ثم يرسل النص بخط عريض. ويستخدم معرّفًا يجمع اسم المصدر ورقم المنشور حتى لا تتداخل سجلات القناتين.

## الإعداد

1. أنشئ بوتًا عبر `@BotFather`.
2. أضف البوت مشرفًا في قناة النشر مع صلاحية نشر الرسائل.
3. في إعدادات المستودع، افتح **Settings → Secrets and variables → Actions**.
4. أضف Secret باسم `TELEGRAM_BOT_TOKEN` وضع فيه توكن البوت.
5. أضف Variable باسم `TELEGRAM_CHANNEL_ID` وضع فيه معرف قناة النشر، مثل `@my_channel`.
6. من تبويب **Actions** شغّل Workflow يدويًا أولًا للاختبار.

بعد ذلك يمكن تشغيل Workflow من خلال `repository_dispatch` كما في المستودع الأصلي. قد تؤخر GitHub المهام المجدولة أو التشغيلية قليلًا، لذلك لا يُعد هذا نقلًا فوريًا مضمونًا.

## الاختبار المحلي

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="توكن_البوت"
export TELEGRAM_CHANNEL_ID="@معرف_قناتك"
python alymenet_to_telegram.py
```
